Happz is een eenvoudige html review app voor het bijhouden en punten geven voor:
12-uurtjes, bittergarnituur, carpaccio, salades, uitsmijter en overige.

De informatie wordt lokaal opgeslagen, maar de app heeft een export en import functie om backups mogelijk te maken en deze ergens anders weer te importeren.
Geen hoogstaande app, maar eenvoudig om het bij te houden
